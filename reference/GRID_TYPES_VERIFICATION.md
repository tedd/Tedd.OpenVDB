# Extended grid type verification

On **2026-09-04**, `Build-GridTypeReference.ps1` completed **43 managed tests and 32 independent native verifications** against OpenVDB 13.0.1 revision `f42248c35a9f7bb30641a8a74d9075ce7d1ddcaf`, using the Windows x64 toolchain recorded in [compression verification](COMPRESSION_VERIFICATION.md).

The native corpus covers Int64, Boolean, topology Mask, Vec3i, Vec3s and Vec3d grids under compression flags 0, 1, 2 and 3. Vec3s and Vec3d additionally run each compression profile with half encoding. Eight native canonical files capture native full-precision or half-quantized results. Every managed output is loaded by native OpenVDB and compared for every stored value, activity, topology, counts, background and supplied metadata. Int64 values include both signed endpoints and integers exceeding exact Double precision. Floating vectors include signed zero, infinity, quiet NaN, half subnormals, rounding boundaries and overflow. Half conversion processes each component and preserves the native Double-to-Float intermediate conversion.

| Native grid identity | Managed representation |
|---|---|
| `Tree_int64_5_4_3` | `Grid<long>` |
| `Tree_bool_5_4_3` | `Grid<bool>` |
| `Tree_mask_5_4_3` | `MaskGrid` |
| `Tree_vec3i_5_4_3` | `Grid<Vec3i>` |
| `Tree_vec3s_5_4_3` | `Grid<Vec3f>` |
| `Tree_vec3d_5_4_3` | `Grid<Vec3d>` |

Boolean leaf buffers persist an activity mask, origin and separate packed-value mask; mask-grid leaf buffers persist one mask and origin. Both bypass ordinary compressed leaf-value chunks. Their internal nodes still use ordinary compressed Boolean arrays. Origins and Boolean scalar byte values are validated rather than interpreted unchecked.

`MaskGrid` provides a restricted topology-grid API. It keeps leaf value and activity coupled, hides its mutable Boolean backing tree, and exposes deep-copy Boolean snapshots. Importing a Boolean grid rejects leaves whose values disagree with their active masks. The writer checks the same invariant before writing; it does not normalize incompatible data. Internal/root tile value and activity remain independently represented as in the native format. This is not a complete port of every MaskTree overload or specialized storage algorithm; managed mask storage currently uses the Boolean tree internally.

Metadata `vec3i` retains `Coord` as its canonical managed representation for compatibility with the original codec. `Vec3i` input is converted losslessly, and `GetMetadata<Vec3i>`/`TryGetMetadata<Vec3i>` are supported. `vec3s` metadata maps to `Vec3f`. Grid value types remain distinct from the metadata representation.

Additional tests verify independent Boolean values/activity, mask snapshot isolation and instance sharing, invalid mask imports, non-real half-encoding rejection before output, malformed Boolean values, leaf-origin corruption and bounded vector allocation.

Reproduce:

```powershell
./reference/Build-GridTypeReference.ps1 -OpenVdbSource D:/source/openvdb
```

The source-controlled native oracle uses `/bigobj` for the large template instantiation set. Native builds and dependencies are ignored artifacts; ordinary managed tests use committed native fixtures. Runtime code has no native dependency or external compression package. Blosc, nonstandard tree layouts, point grids, legacy versions and full specialized tree APIs remain outside this verified milestone.

The checkpoint review additionally found that materializing a mask leaf from an active, false-valued tile must initialize its bits to `value || active`, as specified by the native `LeafNode<ValueMask>` constructor. The implementation now sets both Boolean value and activity to that merged bit. `mask-inheritance.json`, generated by actual native `touchLeaf` followed by `setActiveState`, records 24 regression cases across three tile levels, four inherited value/activity combinations and both requested states. The regression covers counts, neighboring values/activity, preservation outside the leaf and serialization invariants. It verifies explicit leaf materialization and does not claim native no-op allocation parity for the restricted MaskGrid API.
