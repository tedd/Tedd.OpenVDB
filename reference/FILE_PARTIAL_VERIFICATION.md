# Native File read verification

Source: OpenVDB 13.0.1, commit `f42248c35a9f7bb30641a8a74d9075ce7d1ddcaf`, principally `io/File.cc`, `io/Archive.cc`, `io/GridDescriptor.cc`, `Grid.h` and the Tree4 root/internal/leaf read and clip routines.

`VdbFile.OpenRead` now returns a disposable `VdbFileReader`. A seekable format 225 archive with offsets is indexed by reading the header, file metadata and descriptors, seeking over each grid payload. Grid names and file metadata are available without decoding any tree; metadata-only reads decode just grid metadata and transform. The stream must remain exclusively owned by the reader. Closing it honors `leaveOpen`; successful results remain usable after reader disposal.

The reader exposes native name suffixes (`name[N]`), `HasGrid`, `GetMetadata`, `ReadGridMetadata`, `ReadAllGridMetadata`, selected `ReadGrid`, `GetGrids` and `ReadArchive`. Random-access reads return new grids; eager streaming reads retain native cached identity. Duplicate plain-name selection picks the first descriptor in random-access files, while streaming cached lookup requires a unique name. Lists follow native File name ordering where native File sorts them, and retain file order where its eager cache does.

Metadata-only results have empty trees. Native `copyGridWithNewTree` preserves the source background: this is zero when only metadata was decoded, and the loaded background for streaming files. Transforms follow native copy simplification. Selected native instance reads link the immediate parent only; a parent that is itself an instance can therefore leave an empty tree. The existing `ResolveDependencies` option remains an explicit managed extension. All graph validation is iterative; cycles, missing parents, duplicate unique names and incompatible types are rejected before selection. Half storage flags may differ between an instance and its parent.

World boxes use the selected grid's transform and native node-centered floor conventions over transformed corners. An unsorted box means an unbounded read, including the default empty-box sentinel. Inactive non-background values survive inside the box. Seekable region reads decode the selected topology and intersecting leaf buffers before clipping. Unrelated grids and non-intersecting leaf value payloads are skipped. Active-mask framing, duplicate topology masks, Boolean origins and chunk boundaries are still validated; compressed payload contents and checksums outside the selected region are intentionally not decoded, matching native partial reading. Streaming fallback has already decoded every grid before region selection. Managed leaf storage is still allocated with topology; this is eager regional loading, without mapped or delayed leaf storage. Clipping can split tiles into many leaves, so its allocations and nodes are charged before materialization. An instance is clipped in its own transform, not the parent's transform.

Resource limits include the retained index or eager archive plus each operation's allocations. Operations serialize access to the stream; metadata callback reentrancy is rejected. Per-operation budget failures leave a seekable reader reusable. This does not make returned mutable grids thread-safe. Callback allocation remains trusted application code, as documented for metadata registration. Seekable input length changes are detected; callers must prevent other concurrent content changes.

## Evidence

`file-partial-oracle.cpp` calls native `io::File` directly with delayed loading disabled. Six native archives cover compression flags 0/4/6, offset and streaming forms, float/double/int32/int64/bool/mask grids, affine/frustum/specialized transforms, duplicate and empty names, direct instances and dependency chains. There are 516 native observations over 11 world-box profiles. Managed tests compare names, map types, all metadata text/type pairs, background, active/leaf counts, bounds, sampled values/states/depth and an ordered FNV-1a digest of every stored value and its coordinate/depth/activity.

512 observations compare native results. Four native region profiles expand to 262,148 leaves, exceeding the default 100,000-node limit; those explicitly verify managed budget rejection instead of claiming full value comparison. An additional 44 tests cover skipped corrupt grid buffers, indexing without tree allocation, ownership, repeated reads, stream fallback, native identity/sharing, malformed offsets/descriptors, truncation, missing names, graph corruption, half flags, registry snapshots, callback reentrancy, concurrent serialized reads and failure recovery.

Observed local execution: MSVC 19.51 `/MT`, x64, pinned native static core with zlib and Blosc; .NET 11 SDK 11.0.100-preview.7.26381.103. The selection layer passed 516 native observations and 44 focused tests, with 3,405 integrated I/O/math/partition tests also passing. The subsequent leaf-skipping extension adds 173 tests: 168 scalar/Vec3, half/full precision, six-compression and seven active-mask metadata combinations; four malformed skipped-frame cases; and one independent native corrupted-Blosc experiment. Native File accepts the excluding region but rejects the full read; managed tests compare the resulting full stored-value digest and verify no read overlaps the skipped payload. Two subsequent lifetime regressions verify disposal releases the eager archive and input while returned grids remain usable. Total reader coverage is 735 tests. `Build-FilePartialReference.ps1` regenerates the six primary archives plus the corrupted-buffer archive atomically and runs the managed reader suite. It reuses the codec build's exact dependency versions and hashes documented in `CODEC_VERIFICATION.md`; no native dependency is added to the managed library.

The runtime remains limited to the grid types, compression layouts and format version documented for the existing codec. `File` copy/reopen/change-UUID semantics, mapped and delayed leaf storage, and legacy file versions are outside this milestone.
