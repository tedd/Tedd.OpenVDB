Correctness and storage

21007 tests passed, zero failed or skipped. Coverage includes native fixtures, signed limits, uniform no-op tiles, replaced/detached leaves, compacting collections, Boolean and unmanaged-record values, concurrent frozen-tree readers, and reentrant value equality.

The managed accessor allocation rises from 40 to 552 bytes: 512 additional bytes per accessor. The leaf activity-word alias adds one reference per leaf. The cache retains up to 64 detached leaves until the accessor is reused or cleared; Clear releases them immediately. Internal-node caches and callback registries were removed. Timed steady-state managed loops allocated zero bytes.

Method and limits

Ryzen 9 5950X, Windows x64, .NET 11.0.0-rc.1.26425.128 Release with tiering/PGO enabled, logical CPU 8. The native arm uses pinned OpenVDB 13.0.1 and MSVC x64 Release. Builds, tests, diagnostics and complete dependent timing windows used the shared host performance lock to serialize this task with other benchmark agents.

These measurements cover a warmed UInt16 accessor kernel on this machine. Larger working sets, other value types' performance and complete applications remain unmeasured. Sequential process launches do not establish statistical independence; no significance, p99, PMU or application-speed claim is made. Separate JIT diagnostic launches verify code shape, rather than the exact machine-code version of every timed session.
