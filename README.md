# Tedd.OpenVDB (.NET 11)

A managed C# port of OpenVDB sparse voxel storage, targeting **.NET 11 Preview 7**.
The C++/CLI wrapper projects have been replaced by a native-dependency-free managed library.

**Status: partial port, not a complete 1:1 OpenVDB replacement.** The standard sparse
`Tree4<T,5,4,3>` storage hierarchy and selected math/tools are implemented. The `.vdb`
codec supports one uncompressed Int32/Float/Double grid. Point grids, many volume tools,
specialized tree types, nonlinear maps, NanoVDB and AX remain unimplemented. Compressed
and multi-grid files are unsupported. See [port status](docs/PORT_STATUS.md) and
[upstream inventory](docs/UPSTREAM_INVENTORY.md) before adopting it.

Upstream: [OpenVDB 13.0.1](https://github.com/AcademySoftwareFoundation/openvdb/tree/f42248c35a9f7bb30641a8a74d9075ce7d1ddcaf),
commit `f42248c35a9f7bb30641a8a74d9075ce7d1ddcaf` (2026-09-03). Apache-2.0.

## Build and test

Install the SDK pinned in `global.json`, then:

```powershell
dotnet build Tedd.OpenVDB.slnx -c Release
dotnet test Tedd.OpenVDB.slnx -c Release
dotnet run --project samples/VoxelBlocks -c Release
dotnet run --project benchmarks/Tedd.OpenVDB.Benchmarks -c Release
dotnet pack src/Tedd.OpenVDB -c Release -o artifacts
```

Run the scalar fallback suite separately:

```powershell
$env:DOTNET_EnableHWIntrinsic = '0'
dotnet test Tedd.OpenVDB.slnx -c Release
Remove-Item Env:DOTNET_EnableHWIntrinsic
```

Managed tests do not need C++, native OpenVDB, or a network connection after NuGet
restore. Native comparison fixtures were generated by compiling the pinned upstream
source with MSVC; [reference instructions](reference/README.md) explain regeneration.
CI runs the managed suite on Windows and Linux with intrinsics enabled and disabled.

## Voxel blocks

```csharp
using Tedd.OpenVDB.Math;
using Tedd.OpenVDB.Tree;

var blocks = new VdbTree<ushort>(background: 0); // material 0 = air
var chunk = new CoordBBox(new(-32, -32, -32), new(-1, -1, -1));
blocks.Fill(chunk, 1); // 32,768 solid blocks, represented by uniform tiles
var edit = blocks.GetAccessor();
edit.SetValueOff(new(-16, -16, -16), 0); // replace a block with inactive air
edit.SetValueOn(new(-15, -16, -16), 2);  // another material

ushort[] visibleBlocks = new ushort[(int)chunk.Volume];
blocks.CopyToDense(chunk, visibleBlocks); // Z varies fastest, then Y, then X
blocks.Prune(); // collapse uniform nodes, preserving value and active state
```

Activity and stored value are independent, as in OpenVDB. `SetValueOff(c)` retains
the old value; `SetValueOff(c, 0)` writes zero and turns activity off. `SetValueOnly`
changes the value while preserving activity. Empty/background reads allocate nothing.
Signed 32-bit coordinates include negative positions; bounding boxes are inclusive.

Keep one accessor per worker and synchronize writes externally. Concurrent readers
are supported only while the tree is not modified. Tree structural mutations
invalidate cached accessors automatically. A leaf returned by `TouchLeaf`/`ProbeLeaf`
is a live mutable node; do not retain it across structural changes. Enumerators require
no concurrent mutation. `EnumerateValues` yields a tile once, while
`EnumerateActiveVoxels` expands tiles and can be extremely large.

## Native .vdb interchange

`VdbFile` reads and writes standard OpenVDB format 225 for a single uncompressed
`Grid<int>`, `Grid<float>` or `Grid<double>` with supported metadata and linear
transforms. It has no native runtime dependency. Native OpenVDB generated the reader
fixtures and independently verified the managed writer's output in both directions.

```csharp
using Tedd.OpenVDB;
using Tedd.OpenVDB.IO;

var grid = new Grid<int> { Name = "blocks" };
grid.Tree.SetValueOn(new(1, 2, 3), 7);
using var stream = new MemoryStream();
VdbFile.Write(stream, grid);
stream.Position = 0;
Grid<int> copy = VdbFile.Read<int>(stream);
```

Compression (including active-mask compression), half-float storage, multiple grids,
instances, nonempty file metadata, nonlinear maps and unknown persistent metadata
are rejected explicitly. `ushort` remains supported for in-memory block storage but
is not supported by this initial native codec. Read limits bound input bytes, allocated
payload, node/root counts and metadata. Streams remain open by default; set
`leaveOpen: false` to transfer ownership. Write to a temporary file before replacing
an existing save, because a stream failure can leave partial output.

## Implementation and performance

* Standard 8³ leaves, 16³ lower tables, 32³ upper tables and an unbounded root map.
* Unmanaged contiguous value buffers, compact bit masks, and separate sparse child
  tables reduce reference scanning by the GC.
* Span bulk transfers, fully initialized `GC.AllocateUninitializedArray` buffers,
  local array references and bounded loops support JIT optimization.
* SIMD mask Boolean operations have scalar fallbacks; masks use popcount and
  trailing-zero bit iteration. No architecture-specific native library is required.
* Accessors cache managed leaf objects. They do not keep raw pointers across GC
  safepoints, pin the heap, alter process-wide GC settings, or require manual disposal.

The .NET 11 JIT's bounds-check and branch optimizations apply to these loops. No
speedup over .NET 10 or C++ is asserted without a controlled comparison. The benchmark
is an allocation/throughput smoke test; see [performance notes](docs/PERFORMANCE.md).
